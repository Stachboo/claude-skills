# دليل البدء السريع

هذا الدليل للمبتدئين. التوثيق الكامل بالإنجليزية في [`README.md`](README.md) و[`SKILL.md`](SKILL.md).
النسخة الفرنسية في [`GUIDE.fr.md`](GUIDE.fr.md).

## ما هذه المهارة؟

`arabic-writing` مهارة تضاف إلى مساعد الذكاء الاصطناعي.
تعمل مع Claude Code وCodex وGemini CLI وCursor وغيرها.
تساعد المساعد على مراجعة النصوص بالعربية الفصحى المعاصرة وعلى كتابتها.

تفحص علامات الترقيم والترميز وكثافة التشكيل وطول الجمل.
كل ملاحظة تذكر مصدرها: قرار مجمع لغوي أو دليل أسلوب منشور.

هدفها الأول منع الذكاء الاصطناعي من اختراع قاعدة لا وجود لها.
النموذج يراجع العربية جيدًا، لكنه قد يجزم بقاعدة غير موجودة.
ومن لا يقرأ العربية لا يميز القاعدة المخترعة من القاعدة الحقيقية.

لا تحتاج إلى قراءة العربية لاستعمالها، فالملاحظات تصدر بالإنجليزية.

## ما لا تفعله

- لا تصحح الإملاء ولا النحو.
- لا تفتي في مسائل الفقه.
- لا تحسم المسائل التي اختلفت فيها المجامع اللغوية.
- النص الذي يقتبس القرآن أو الحديث يراجعه شخص مؤهل قبل نشره.

## الخطوة الأولى: تأكد من وجود بايثون

تحتاج المهارة إلى بايثون (Python) بالإصدار 3.8 أو أحدث، ولا شيء غيره.

افتح الطرفية، وعلى ويندوز افتح PowerShell، ثم اكتب:

```
python --version
```

على ماك ولينكس اكتب `python3` بدل `python` في هذا الدليل كله.

إن لم يجد الجهاز الأمر فثبّت بايثون من [python.org](https://www.python.org/downloads/).
على ويندوز فعّل خيار **Add python.exe to PATH** أثناء التثبيت.

## الخطوة الثانية: ثبّت المهارة

أسهل طريقة لا تحتاج إلى أي أداة:

1. افتح [github.com/Stachboo/claude-skills](https://github.com/Stachboo/claude-skills).
2. اضغط **Code** ثم **Download ZIP**.
3. فك ضغط الملف.
4. انسخ مجلد `skills/arabic-writing` إلى مجلد المهارات عند مساعدك.

| المساعد | المجلد |
|---|---|
| Claude Code | `~/.claude/skills/` |
| Codex وGemini CLI وCursor | `~/.agents/skills/` |

الرمز `~` يعني مجلدك الشخصي.
على ويندوز هو `C:\Users\` متبوعًا باسم حسابك.
أنشئ مجلد `skills` إن لم يكن موجودًا.

في Claude Code يكفي أمران:

```
/plugin marketplace add Stachboo/claude-skills
/plugin install stachboo-skills@stachboo-skills
```

ثم أعد تشغيل المساعد.

## الخطوة الثالثة: استعملها مع مساعدك

لا تحتاج إلى حفظ أي أمر. اطلب ما تريد بلغتك، ومن الأمثلة:

- «راجع هذا النص العربي، وهو مقال صحفي.»
- «اكتب فقرة بالعربية لقراء ليس لهم تكوين ديني.»
- «افحص هذه الصفحة العربية قبل نشرها.»

أخبر المساعد دائمًا لمن تكتب، فهذا ما يحدد أقصى طول للجملة.

## الخطوة الرابعة (اختيارية): شغّل الفاحص بنفسك

احفظ نصك في ملف بترميز UTF-8.
في برنامج المفكرة على ويندوز اختر «حفظ باسم» ثم اختر الترميز UTF-8.

ادخل إلى مجلد المهارة ثم اكتب:

```
python scripts/check.py text.txt --preset news
```

### اقرأ النتيجة

السطر الأخير يلخص كل شيء، مثل `2 hard, 0 recommendation, 0 divergence`.

| الدرجة | معناها | ماذا تفعل؟ |
|---|---|---|
| **hard** | خطأ ثابت له مصدر | صحّحه |
| **recommendation** | مسألة تقدير | القرار لك |
| **divergence** | المجامع مختلفة فيها | لا تصحيح، للعلم فقط |

كل ملاحظة تذكر القاعدة والتصحيح والمصدر.

ويعيد البرنامج رمز خروج يفيدك إن أردت الأتمتة.
الرمز **0** يعني لا خطأ ثابت.
الرمز **1** يعني خطأ ثابت واحد على الأقل.
الرمز **2** يعني أن الفحص لم يتم: ملف مفقود أو ترميز خاطئ أو إعداد مجهول.
الرمز 2 لا يحكم على النص. أصلح المدخل ثم أعد التشغيل.

### اختر الإعداد المناسب

| الإعداد | لأي نص؟ |
|---|---|
| `news` | خبر أو مقال صحفي |
| `magazine` | مقال مجلة أو تحليل |
| `literary` | قصة أو نص أدبي |
| `legal` | نص قانوني أو إداري |
| `reference` | نص مرجعي أو تقني أو علمي |
| `religious` | نص ديني |
| `children` | نص للأطفال |

لنص مبسّط موجّه إلى **الكبار** المبتدئين استعمل:

```
python scripts/check.py text.txt --preset children --set diacritics=functional
```

## إذا واجهتك مشكلة

| الرسالة | الحل |
|---|---|
| `command not found` أو `is not recognized` | جرّب `python3` أو `py`، أو ثبّت بايثون (الخطوة الأولى) |
| `cannot read … No such file` | تحقق من اسم الملف ومكانه |
| `it is not UTF-8` | احفظ الملف من جديد بترميز UTF-8 (الخطوة الرابعة) |
| `Unknown preset` | اختر أحد الأسماء في الجدول أعلاه |
